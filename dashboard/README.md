# OmniStyle Power BI Dashboard

This folder contains everything needed to build the OmniStyle Power BI
dashboard on top of the platform's analytics output.

## Contents

- **`power_bi_guide.md`** — the full dashboard build guide: data model,
  relationships, page-by-page layout, and recommended DAX measures.
- **`sample_data/`** — Power BI-ready CSV exports generated by
  `python -m src.train_model`:
  - `customers.csv` — cleaned customer dimension data
  - `products.csv` — cleaned product dimension data
  - `orders.csv` — cleaned order header data
  - `sales_detail.csv` — order line items joined with product and order
    context (the primary fact table for most visuals)
  - `customer_360.csv` — one row per customer combining demographics, RFM
    features, segment label, and churn probability (used for the Customer
    Intelligence dashboard page)

## Why CSV instead of a `.pbix` file

This project intentionally ships **Power BI-ready CSV files** rather than a
pre-built `.pbix` file, because a `.pbix` requires the actual Power BI
Desktop application to author and cannot be meaningfully generated by a
script. Follow `power_bi_guide.md` to import these CSVs into Power BI
Desktop and build the dashboard described there — it should take well under
an hour for someone already familiar with Power BI.

## Regenerating the sample data

The files in `sample_data/` are build artifacts, not hand-maintained data.
To regenerate them from scratch (e.g., after changing the synthetic data
volume or model), run the full pipeline from the project root:

```bash
python -m src.data_ingestion
python -m src.data_cleaning
python -m src.feature_engineering
python -m src.train_model
```

`src.train_model` is the step that writes into `dashboard/sample_data/`.
